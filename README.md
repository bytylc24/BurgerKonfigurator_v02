# Burger-Konfigurator

JavaFX-Anwendung (HTL, 3. Klasse, Projekt 11), mit der man eigene Burger zusammenstellt.
Design Pattern: **Immutable**.

## Voraussetzungen

- Java 21 (oder neuer)
- Maven muss nicht installiert sein, der Maven Wrapper (`mvnw`) ist dabei.

## Starten

Windows:

```
mvnw.cmd javafx:run
```

macOS / Linux:

```
./mvnw javafx:run
```

## Tests

```
mvnw.cmd clean test
```
